# Thư Mục Hình Ảnh (Images)

Nơi lưu trữ các hình ảnh tĩnh của chiến dịch thiện nguyện "Nắng Ấm Trao Em":
- Banner, ảnh hero
- Ảnh các chuyến đi thực địa (Hà Giang, Điện Biên, Sơn La)
- Logo và biểu tượng chiến dịch

*Lưu ý:* Hiện tại trang web đang sử dụng hình ảnh từ CDN chất lượng cao Unsplash và mã VietQR API. Bạn có thể tải hình ảnh về thư mục này và đổi đường dẫn trong `index.html` thành `assets/images/ten-anh.jpg`.
